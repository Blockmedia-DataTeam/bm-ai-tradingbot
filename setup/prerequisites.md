# 준비물

1화에서 소개한 준비물 네 가지와, 2화 전에 갖출 프로그램과 폴더입니다. 코딩 지식은 준비물에 없습니다. 터미널을 처음 보셔도 됩니다.

## 1. 24시간 켜둘 컴퓨터

봇은 잠들면 안 됩니다. 시세 감시와 손절 감시가 같이 멈춥니다. 조건은 두 가지입니다.

- 항상 전원에 연결
- 절전 모드 해제

맥미니가 편하지만 노트북, 미니 PC, 남는 데스크톱도 됩니다. 노트북이면 덮개를 닫아도 잠들지 않게 설정합니다.

맥 절전 해제 확인
```
pmset -g
```
출력에서 `sleep` 값이 `0`이어야 합니다. 아니면 시스템 설정 > 배터리 또는 에너지 절약에서 "디스플레이가 꺼져 있을 때 자동으로 잠자기 방지"를 켭니다.

제가 겪은 사고: 맥미니가 잠들면서 1분 감시 루프가 멈춘 적이 있습니다. 1화 실패담 1번이 이 이야기입니다.

## 2. 업비트 계좌와 API 키

- 계좌 개설과 API 키 발급은 무료입니다
- 시리즈 후반까지는 **자산조회 권한만** 씁니다. 주문 권한은 실전 회차에서 다룹니다
- **출금 권한은 어떤 단계에서도 부여하지 않습니다**
- 발급 시 IP 화이트리스트에 봇이 돌 컴퓨터의 IP를 등록합니다

키 발급은 3화에서 실제로 필요해질 때 다시 안내합니다. 지금 발급할 필요는 없습니다.

## 3. Claude Code 구독과 Anthropic API

둘은 다른 물건입니다.

| | Claude Code | Anthropic API |
|---|---|---|
| 언제 쓰나 | 봇을 만들 때 | 봇이 돌면서 AI 판단을 받을 때 |
| 과금 | 구독제 | 사용량 과금 |
| 언제 필요 | 2화부터 | 8화 AI 참모 회차부터 |

2화 시점에는 Claude Code만 있으면 됩니다. 설치는 `claude-code-install.md`.

## 4. 텔레그램 계정

체결 알림과 일일 리포트를 받는 창구입니다. 무료. 봇 토큰 발급은 7화에서 다룹니다.

## 5. 준비 프로그램 셋

2화부터 씁니다. 셋 다 무료로 내려받습니다.

- **VS Code**: 편집기. 공식 사이트(code.visualstudio.com)에서 내려받아 응용 프로그램 폴더에 끌어 놓습니다. 2화에서는 AI가 만든 `CLAUDE.md`를 읽는 데 씁니다
- **클로드 데스크탑 앱**: 공식 사이트(claude.ai/download)에서 내려받고 클로드 구독 계정으로 로그인합니다. 지시문을 내 상황에 맞게 다듬을 때와 `ep02/prompt_limits.md`에 씁니다. 클로드코드와 다른 프로그램입니다
- **클로드코드**: 터미널에서 설치합니다. 절차는 `claude-code-install.md`

## 6. 봇 폴더 만들기

- 위치는 홈 폴더(Finder 사이드바의 집 모양). 바탕화면과 문서 폴더는 아이클라우드 동기화 대상이라 피합니다. 다운로드 폴더도 피합니다
- 이름은 `tradingbot`. 영문 소문자, 띄어쓰기와 한글 없이
- 폴더 이름은 자유다. 이 문서는 tradingbot 을 예로 쓰고, 2화 영상에서는 practice-ai-tradingbot 을 썼다. 영문 소문자, 띄어쓰기와 한글 없이라는 규칙만 지킨다.
- 터미널에서 들어가는 명령

```
cd ~/tradingbot
```

- 이 폴더에서 `claude`를 실행하면 클로드코드가 이 폴더 안에서만 일합니다

## 7. 클로드코드 첫 실행

처음 실행하면 화면 색 선택과 로그인을 묻습니다. 로그인은 클로드 구독 계정 그대로. 로그인 뒤 준비 화면이 뜨면 끝입니다.
