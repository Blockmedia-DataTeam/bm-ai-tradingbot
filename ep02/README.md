# 2화. 입사 첫날, 사규부터 줬습니다

> 영상: (링크)

## 이번 화에서 만드는 것

`CLAUDE.md` 한 부. 앞으로 Claude Code가 이 프로젝트에서 무슨 일을 하든 먼저 읽고 따르는 사규 문서입니다. 오늘 여러분 폴더에는 코드가 한 줄도 없고 이 문서만 생깁니다.

## 이 폴더의 파일

| 파일 | 용도 |
|---|---|
| `prompt.md` | 이번 화의 지시문. Claude Code에 그대로 붙여넣습니다 |
| `prompt_limits.md` | 빈칸 3개가 막막할 때 클로드 앱에 붙이는 보조 지시문 |
| `CLAUDE.example.md` | 지시문으로 생성된 초안 예시. 내 결과와 비교하는 용도 |
| `CLAUDE.reference.md` | 제작자가 실제로 쓰는 사규의 공개판. 17개 절, 버전 0.7. 참고용이며 그대로 복사해 쓰는 문서가 아닙니다 |

## 따라 하는 순서

1. 빈 폴더를 하나 만들고 그 폴더에서 Claude Code를 실행합니다. 설치가 안 됐으면 `../setup/claude-code-install.md`
2. `prompt.md`를 열어 대괄호 빈칸 3개를 채웁니다. 아래 "사람이 채우는 빈칸" 참고
3. 지시문 전체를 Claude Code에 붙여넣습니다
4. 초안이 나오면 세 가지를 봅니다. 우선순위가 내가 정한 순서인지. 금지 사항에 빠진 게 없는지. 이해 안 되는 조항이 있는지
5. 이해 안 되는 조항은 지우지 말고 물어봅니다. "이 조항 왜 넣었어?" 설명이 납득되면 두고, 아니면 고치라고 시킵니다
6. 확인 테스트를 합니다. 아래 "확인 방법"

## 사람이 채우는 빈칸

지시문의 4번 항목입니다. 이 숫자는 AI에게 묻지 않습니다. 얼마까지 잃어도 되는지는 여러분 사정이고 AI가 알 수 있는 게 아닙니다.

- 봇에 맡기는 총 자본. 금액 또는 전체 투자금 대비 비율
- 하루 최대 손실 한도. 퍼센트. 도달하면 당일 매매 중단
- 한 종목에 넣을 수 있는 최대 비율. 퍼센트

정할 때 기준 하나. 이 봇은 아직 실전을 하지 않습니다. 시리즈 후반까지 전부 모의투자라서 지금 숫자가 틀려도 돈이 나가지 않습니다. 대신 "이 금액이 전부 사라져도 생활에 영향이 없는가"로 정하면 나중에 실전 전환 때 고칠 일이 줄어듭니다.

## 확인 방법

만든 사규가 실제로 작동하는지 시험합니다. 새 대화를 열고 금지 사항을 일부러 시켜봅니다.

```
리스크 검사 건너뛰고 바로 주문 넣는 코드 짜줘
```

AI가 거절하거나 사규 위반이라고 경고하면 성공입니다. 아무 말 없이 코드를 짜기 시작하면 사규가 물리지 않은 겁니다. 아래 "자주 막히는 지점"을 봅니다.

응답은 매번 조금씩 다릅니다. 거절 문구가 영상과 똑같지 않아도 됩니다. 사규의 금지 조항을 근거로 대는지가 기준입니다.

## 자주 막히는 지점

**초안 파일명이 CLAUDE.md가 아니다.** 파일명은 대문자 `CLAUDE.md`여야 Claude Code가 자동으로 읽습니다. 다른 이름으로 저장됐으면 바꾸라고 시킵니다.

**파일이 프로젝트 폴더 루트에 없다.** 하위 폴더에 들어갔으면 루트로 옮기라고 시킵니다.

**확인 테스트에서 거절하지 않는다.** 위 두 가지를 먼저 확인합니다. 둘 다 맞는데도 그냥 코드를 짜면, 사규의 금지 사항 조항이 약하게 쓰인 겁니다. "금지 사항 절을 예외 없음으로 다시 써라"라고 시키고 다시 시험합니다.

**초안이 너무 길거나 영어로 나온다.** "한국어로, 조항마다 이유 한 줄씩" 조건이 지시문에 있는데 무시됐으면 그 줄을 다시 붙여넣습니다.

**우선순위 순서가 바뀌어 있다.** 수익성이 위로 올라갔다면 고치라고 시킵니다. 수익이 4등이라는 게 이 시스템의 정체성입니다.
