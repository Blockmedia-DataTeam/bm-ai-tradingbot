2화 지시문: AI 사규 만들기
터미널에서 홈 폴더의 tradingbot 폴더로 들어가 클로드코드를 실행한 뒤, 아래를 그대로 붙여넣는다. 폴더 만드는 규칙은 setup/prerequisites.md 에 있다. 대괄호 세 개만 본인 숫자로 채운다. 숫자가 막막하면 prompt_limits.md 를 먼저 쓴다.

```
업비트 KRW 현물 시장에서 도는 24시간 자동매매 봇을 너와 함께 만들 거다.
코드를 짜기 전에, 이 프로젝트에서 네가 항상 따라야 할 사규 문서(CLAUDE.md)부터 작성해라.

다음을 반드시 포함한다.

1. 우선순위 (충돌하면 위가 이긴다)
   1) 자본 보전  2) 시스템 안정성  3) 모든 결정의 근거 기록  4) 수익성  5) 개발 속도

2. 검증 순서: 어떤 전략도 "백테스트 통과 → 모의투자 2주 이상 → 소액 실전" 순서를
   건너뛸 수 없다.

3. 금지 사항 (예외 없음)
   - 리스크 한도를 코드에서 올리는 것 (내리는 것만 허용)
   - 출금 관련 기능 구현
   - 검증 안 된 전략을 실전 계좌에 연결
   - API 키를 코드나 로그에 적는 것
   - AI 판단을 안전장치 없이 곧바로 주문으로 연결

4. 내가 정하는 값 (이 숫자는 내가 정한다. 네가 임의로 바꿀 수 없다)
   - 봇에 맡기는 총 자본: [금액 또는 비율]
   - 하루 최대 손실 한도: [퍼센트] (도달 시 당일 매매 중단)
   - 한 종목에 넣을 수 있는 최대 비율: [퍼센트]

5. 알림 메시지 말투: 빈말 없이 숫자와 사실만. 근거 없는 확신 표현 금지.

문서는 한국어로, 각 조항에 "왜 이 규칙이 필요한지" 한 줄 이유를 달아라.

이 문서는 네가 작업을 시작할 때마다 통째로 읽는다. 길수록 토큰이 낭비된다. 그래서
- 전체 100줄 이내로 쓴다. 조항은 한두 줄, 이유는 한 줄.
- 같은 내용을 두 번 쓰지 않는다. 인사말, 요약, 맺음말을 넣지 않는다.
- 위에 없는 절을 네 판단으로 늘리지 않는다. 필요해 보이는 게 있으면 문서에 넣지 말고 나한테 제안만 해라.
- 앞으로 이 문서를 고칠 때도 같은 기준을 지킨다. 이 기준 자체를 문서 마지막 조항으로 넣어라.

작성 후, 내가 이해하기 어려울 만한 조항 3개를 골라 먼저 설명해라. 설명은 문서에 넣지 말고 채팅으로 답해라.

```
