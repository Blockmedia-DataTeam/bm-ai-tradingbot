# CLAUDE.md — 업비트 KRW 자동매매 봇 사규

이 문서는 작업 시작마다 전체를 읽는다. 모든 조항 중 충돌이 있으면 우선순위가 높은 쪽이 이긴다.

## 1. 우선순위 (위가 이긴다)
1. 자본 보전 — 잃으면 복구 불가능한 자본을 지키는 것이 이 봇의 존재 이유다.
2. 시스템 안정성 — 죽거나 오작동하는 봇은 전략 품질과 무관하게 손실을 만든다.
3. 모든 결정의 근거 기록 — 근거 없이는 사후에 무엇이 잘못됐는지 알 수 없다.
4. 수익성 — 위 세 가지가 지켜진 다음에만 의미가 있다.
5. 개발 속도 — 가장 마지막이다. 빨리 만드는 것이 사고의 핑계가 될 수 없다.

## 2. 검증 순서 (생략 불가)
백테스트 통과 → 모의투자 2주 이상 → 소액 실전. 단계를 건너뛴 전략은 어떤 이유로도 실행하지 않는다.
— 과거 데이터에서의 성공은 실시간 환경, 슬리피지, 체결 실패를 검증하지 못하기 때문이다.

## 3. 금지 사항 (예외 없음)
- 리스크 한도를 코드에서 올리는 것 (내리는 것만 허용) — 한도 상향은 항상 손실 확대 방향이라 되돌릴 수 없는 피해로 이어진다.
- 출금 관련 기능 구현 — 자동매매 봇에 자금 이동 권한까지 주면 오류 하나가 자본 전액 유출로 번진다.
- 검증 안 된 전략을 실전 계좌에 연결 — 2번 조항의 검증 순서를 무력화하는 우회로를 원천 차단한다.
- API 키를 코드나 로그에 적는 것 — 저장소나 로그가 유출되면 계좌 전체가 탈취당한다.
- AI 판단을 안전장치 없이 곧바로 주문으로 연결 — AI는 틀릴 수 있고, 사람이나 자동 한도 검증 없이 바로 주문이 나가면 오판이 즉시 손실로 이어진다.

## 4. 파라미터
- 총 자본: 1,000,000 KRW
- 일일 최대 손실 한도: 10%
- 종목당 최대 비중: 40%

## 5. 알림 메시지 원칙
숫자와 사실만 전달한다. 근거 없는 확신 표현("확실히 오릅니다" 등)은 금지한다.
— 확신 표현은 실제 불확실성을 가리고 사람의 판단을 왜곡시킨다.
