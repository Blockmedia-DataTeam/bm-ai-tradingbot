# 업비트 API 키 발급

3화 영상 2부를 글로 옮긴 것입니다. 영상 없이 이 문서만 보고 따라 해도 됩니다. 확인일 2026-10-22. 업비트 화면은 바뀔 수 있으니 메뉴 이름이 다르면 비슷한 것을 찾습니다.

## 키가 필요한 일과 아닌 일

| 하는 일 | 키 |
|---|---|
| 시세, 캔들 조회 | 필요 없음. 공개 API |
| 내 잔고 조회 | 필요. 자산조회 권한 |
| 주문 | 필요. 주문조회, 주문하기 권한 |
| 출금 | 필요. 이 시리즈에서는 끝까지 주지 않습니다 |

3화에서 당장 쓰는 건 잔고 조회 하나입니다. 그래도 키는 한 번에 만들어 둡니다. 나중에 권한을 추가하려면 키를 새로 발급받아 교체해야 해서입니다.

## 발급 순서

PC 웹에서만 됩니다. 모바일 앱으로는 발급이 안 됩니다.

1. 업비트 홈페이지에 로그인합니다.
2. 고객센터 > Open API 안내 > Open API 사용하기 순서로 들어갑니다. 본인인증을 한 번 더 요구합니다.
3. 권한을 고릅니다. **자산조회, 주문조회, 주문하기** 세 개를 체크합니다. 출금 관련 항목은 체크하지 않습니다.
4. IP 주소를 입력합니다. 봇이 돌아갈 컴퓨터에서 https://ip.pe.kr 에 접속하면 바로 보입니다. 그 값을 복사해 넣습니다. 비워 둘 수 없습니다.
5. 개인정보 수집 동의에 체크하고 발급 버튼을 누릅니다.
6. Access Key 와 Secret Key 두 줄이 나옵니다. **Secret Key 는 이 화면에서 한 번만 보여 줍니다.** 창을 닫기 전에 둘 다 복사합니다.

## 복사한 키를 두는 곳

키는 비밀번호입니다. 코드 파일에 적거나 클로드코드 채팅창에 붙여넣으면 비밀번호를 포스트잇에 써서 현관문에 붙여 두는 것과 같습니다. 코드는 나중에 공유하거나 어딘가에 올리게 되고, 채팅은 기록에 남습니다.

1. VS Code 로 봇 폴더를 엽니다.
2. 폴더 바로 아래에 `.env` 라는 파일을 새로 만듭니다. 이름은 점으로 시작합니다. 이 폴더의 `.env.example` 과 같은 모양입니다.
3. 두 줄을 손으로 넣고 저장합니다. `여기에` 자리에 복사한 키를 붙여넣습니다.

```
UPBIT_ACCESS_KEY=여기에
UPBIT_SECRET_KEY=여기에
```

봇은 이 파일을 읽기만 합니다. 키 문자열은 코드 어디에도 들어가지 않습니다. 나중에 깃허브 같은 데 코드를 올릴 일이 생기면 이 파일 하나만 빼면 됩니다.

## 알아 둘 것

- **IP 가 바뀌면 키가 막힙니다.** 집 인터넷은 공인 IP 가 가끔 바뀝니다. 어느 날 봇이 계좌를 못 읽으면 키보다 IP 를 먼저 의심합니다. 발급 페이지에서 바뀐 IP 를 다시 등록하면 됩니다. 키 하나에 열 개까지 등록할 수 있습니다.
- **주문 권한이 있는 키입니다.** 봇이 이 권한을 쓰는 건 모의투자를 다 거친 뒤입니다. 그 전까지 3화 지시문은 주문 API 호출을 금지하고, 2화 사규도 리스크 검사 없는 주문을 막습니다.
- **실습이 끝나면 지워도 됩니다.** 발급 페이지에서 삭제할 수 있고 다음에 필요하면 다시 발급받으면 됩니다.
- 출금 권한은 어떤 단계에서도 주지 않습니다. 봇이 해킹당하거나 오작동해도 출금 권한이 없으면 돈이 계좌 밖으로 나갈 방법이 없습니다.

- [요청 수 제한 안내](https://docs.upbit.com/docs/user-request-guide) IP 등록 규칙
