# bm-ai-tradingbot

유튜브 시리즈 **AI 직원 고용기: 24시간 트레이딩봇**의 시청자 배포 자료입니다.
코딩 없이 만들고, 검증 없인 안 굴립니다. 업비트 자동매매 풀세트.

영상에서 제가 Claude Code에 실제로 넣은 지시문, 그 지시문으로 나온 결과물 예시, 따라 하다 막힐 때 볼 문서를 회차 순서대로 올립니다. 영상이 공개될 때 해당 회차 폴더가 추가됩니다.

> 재생목록: (링크)

## 이 레포에 있는 것과 없는 것

있는 것
- 회차별 지시문 원문. 영상에서 보여준 것과 글자 단위로 같습니다
- 회차별 결과물 예시. 내가 따라 한 결과가 비슷하게 나왔는지 비교하는 용도
- 제가 쓰는 실물 문서의 공개판
- 설치 절차, 준비물, 확인 체크리스트

없는 것
- 봇 코드 저장소 전체

코드를 통째로 드리지 않는 이유는 1화에서 설명했습니다. 복사해서 돌리면 이해 없이 돈만 걸게 되고, 봇이 고장 났을 때 대응할 수 없습니다. 지시는 직접 내려야 합니다. 이 레포는 그 지시를 정확히 내릴 수 있게 돕는 자료입니다.

## 시작하기

1. `setup/prerequisites.md`에서 준비물 4가지를 확인합니다
2. `setup/claude-code-install.md`대로 Claude Code를 설치합니다
3. 회차 폴더의 README를 열고 순서대로 따라 합니다

## 고지

이 시리즈와 레포는 투자 조언이 아닙니다. 디지털자산 자동매매는 원금 전액 손실 가능성이 있으며, 모든 투자 판단과 책임은 본인에게 있습니다. 영상에 나오는 매매는 전부 가상 자본으로 돌리는 모의투자입니다. 이 자료를 따라 만든 봇의 운용 결과에 대해 제작자는 책임지지 않습니다.
