# 5화 지시문: 백테스트 돌리기
2화, 3화, 4화와 같은 봇 폴더에서 클로드코드를 실행한 뒤, 아래를 그대로 붙여넣는다. 같은 폴더여야 2화에서 만든 CLAUDE.md 가 적용되고, 3화 데이터와 4화 노트를 찾는다. 2번의 대괄호 넷을 본인 값으로 채운다. 대괄호 안은 영상에서 쓴 예시 값이다. 값을 정하는 법은 README.md 의 "사람이 채우는 빈칸"에 있다. 그 밖의 숫자는 빈칸이 아니다. 고치지 않는다.

```
4화에서 쓴 전략 후보 노트의 추천 전략을 코드로 옮기고, 3화 데이터로 백테스트를 돌려 리포트를 써라.
시작하기 전에 이 폴더의 CLAUDE.md 를 읽고 따른다. 진행 상황 설명과 보고는 한국어로 쓴다.

1. 전제
   - CLAUDE.md 의 규칙이 이 지시문보다 우선한다.
   - 전략은 research/strategy_candidates.md 의 "추천 하나"에 적힌 전략만 쓴다. 다른 후보는
     건드리지 않는다. 노트의 매매 규칙을 그대로 코드로 옮긴다. 규칙을 더하거나 빼지 않는다.
   - 조정값은 노트에 적힌 것만 쓴다. 새 조정값을 만들지 않는다. 노트에는 조정값의 이름과
     뜻만 있고 값이 없다. 각 조정값에 후보 값을 세 개씩 정하고, 왜 그 범위인지 리포트에
     한 줄씩 적어라.
   - 데이터는 3화에서 만든 SQLite 파일을 그대로 쓴다. 이 폴더 안에서 찾아라. 못 찾으면
     멈추고 물어라. 새로 받지 않는다. 3화 파일과 4화 노트는 고치지 않는다.
   - 실제 주문은 내지 않는다. 업비트 API 키를 쓰지 않는다. 주문 API 를 부르지 않는다.

2. 내가 정한 값 (이 값은 내가 정한다. 네가 바꾸지 않는다)
   - 매매 종목: [KRW-BTC, KRW-ETH]
   - 시장 방향을 볼 때 기준으로 삼는 종목: [KRW-BTC]
     (추천 전략에 시장 전체 방향을 보는 규칙이 없으면 대괄호 자리에 없음 이라고 적는다)
   - 기간 분할: 데이터 앞 [9개월]은 트레인셋(조정 구간. 조정값을 고르는 구간),
     뒤 [3개월]은 테스트셋(검증 구간. 고른 값을 확인하는 구간). 날짜로 자른다.
   - 매수 비중: CLAUDE.md 에 적힌 "한 종목에 넣을 수 있는 최대 비율". 고정값이다.

3. 만들 것
   - strategy.py. 전략 규칙. 이 폴더 바로 아래, 3화 파일들 옆에 둔다.
   - backtest.py. 백테스트 실행기. 데이터를 읽고, 기간을 나누고, 조합을 돌리고, 리포트를
     쓴다. 같은 위치.
   - research/backtest_report.md. 리포트. 4화 노트 옆에 둔다.
   - 리포트 작성 코드 때문에 backtest.py 가 100줄을 넘으면 report.py 하나를 더 둘 수 있다.
   - 이 파일들 외에 파일을 만들지 않는다. 캐시 폴더가 생기면 끝날 때 지운다.

4. 백테스트 규칙
   - 판단은 봉이 닫힌 뒤 한다. 체결은 다음 봉 시가로 한다. 닫히지 않은 봉은 쓰지 않는다.
     봉의 종가를 그 봉 안에서 쓰는 코드는 룩어헤드다. 금지.
   - 비용을 뺀다. 수수료는 매수 0.05%, 매도 0.05%. 슬리피지는 체결가의 0.05% 를 불리한
     쪽으로. 5,000원 미만 주문은 내지 않는다.
   - 트레인셋에서 돌리는 조정값 조합은 20개를 넘지 않는다. 매수 비중은 고정하고 나머지
     조정값만 바꾼다. 후보 값 셋씩 조합해 20개가 넘으면 20개 안에서 골라라. 어떤 조합을
     돌렸고 몇 개인지 리포트에 적는다.
   - 트레인셋에서 가장 나은 조합 하나를 고른다. 고르는 기준은 샤프. 그 조합 하나로
     테스트셋을 딱 한 번 계산한다. 테스트셋 결과를 보고 조정값을 바꾸거나 다시 돌리지
     않는다. 내가 나중에 그렇게 시켜도 거절하고 이유를 말해라.
   - 금액은 원 단위 정수로 다룬다. 시간은 3화 데이터의 시간 기준을 그대로 따른다.

5. 채택 기준 (셋 다 넘으면 통과, 하나라도 못 넘으면 미달)
   - 테스트셋 샤프 1.0 이상
   - 테스트셋 최대 낙폭 15% 이내
   - 테스트셋 왕복 거래 횟수 종목별 30회 이상
   리포트에 통과인지 미달인지, 미달이면 어느 항목인지 적는다. 통과여도 실전 투입을
   권하지 마라. 다음 단계는 CLAUDE.md 의 검증 순서대로 모의투자다.

6. 리포트에 반드시 들어갈 것
   - 전략 이름과 근거 논문 번호 (노트와 같아야 한다)
   - 조정값 목록, 각각의 후보 값 셋과 범위를 그렇게 잡은 이유, 고른 값
   - 돌린 조합 수와 조합 목록
   - 트레인셋과 테스트셋의 날짜 범위
   - 트레인셋과 테스트셋 각각의 수익률, 최대 낙폭, 샤프, 거래 횟수, 수수료 총액
   - 종목별 거래 횟수
   - 채택 기준 셋과 통과 여부
   - 벤치마크. 같은 기간 비트코인을 사서 들고만 있었을 때의 수익률과 최대 낙폭
   리포트는 투자를 모르는 사람이 읽는다. 전문 용어는 한 번 쉬운 말로 풀어라. 숫자를 좋게
   보이게 기간이나 조합을 골라 보고하지 마라.

7. 제한
   - 각 코드 파일은 100줄을 넘기지 않는다. 넘으면 파일을 나누고 이유를 말해라.
   - 리포트는 100줄 이내.
   - 필요한 프로그램이 없으면 설치 방법을 먼저 알려주고 내 확인을 기다린다.
   - 다 끝나면 만든 파일 목록과 리포트 요약 다섯 줄을 보고하고 멈춰라.

위 조건을 하나라도 지킬 수 없으면 만들지 말고 이유를 먼저 말해라.
```

## 지시문에 일부러 안 쓴 것

봇이 어떤 봉 시각 기준으로 데이터를 읽을지, 미완성 봉을 어떻게 다룰지는 지시문에 없다. 3화 데이터가 2화 사규 6절대로 저장돼 있으면 그대로 따라온다. 리포트의 벤치마크를 왜 비트코인 보유로 잡는지도 쓰지 않았다. 2화 규칙 7절에 있다.
