# 4화 지시문: 전략 후보 노트 만들기
2화, 3화와 같은 봇 폴더에서 클로드코드를 실행한 뒤, 아래를 그대로 붙여넣는다. 같은 폴더여야 2화에서 만든 CLAUDE.md 가 적용된다. 이 ep04 폴더가 봇 폴더 안에 복사돼 있어야 한다. 대괄호 세 개만 본인 성향으로 채운다. 막막하면 README.md 의 "사람이 채우는 빈칸"을 먼저 본다.

```
연습 폴더에 전략 후보 노트를 만들어라. 결과물은 research/strategy_candidates.md 파일 하나다.
시작하기 전에 이 폴더의 CLAUDE.md 를 읽고 따른다.

1. 전제
   - CLAUDE.md 의 규칙이 이 지시문보다 우선한다.
   - ep04/papers.md 에 있는 논문만 근거로 써라. 목록 밖의 논문이나 출처를 적지 마라.
     논문 제목과 저자는 papers.md 에 적힌 그대로 옮겨라.
   - 코드를 쓰지 마라. 백테스트를 돌리지 마라. 주문 API 를 부르지 마라.
     이번 작업은 문서 작성이다.
   - 3화에서 만든 데이터 파일은 읽어도 되지만 고치지 마라.

2. 사장의 성향 (이 값은 내가 정한다. 네가 바꾸지 않는다)
   - 매매 빈도: [며칠에 한 번. 자주 들여다보고 싶지 않다]
   - 관심 종목: [비트코인 위주. 이더리움은 보조]
   - 피하고 싶은 것: [하루에 10% 넘게 잃는 것]

3. 노트 구성
   1) 후보 셋. 각 후보마다 아래 다섯 줄만 적어라.
      - 이름
      - 근거 논문 (papers.md 의 번호와 제목)
      - 규칙 세 줄 (언제 사고 언제 파는지. 투자를 모르는 사람도 읽을 수 있게)
      - 조정값 목록 (사람이 정해 줘야 하는 숫자. 이름과 뜻만 적고 값은 적지 마라)
      - CLAUDE.md 와 부딪히는 점 (없으면 "없음")
   2) 추천 하나. 위 성향을 근거로 하나를 고르고 이유를 다섯 문장 이내로 써라.
   3) 아직 모르는 것. 이 전략이 실제로 돈을 벌지 지금 알 수 없는 이유를 두 문장으로 써라.

4. 제한
   - 조정값이 다섯 개를 넘는 후보는 넣지 마라.
   - 수익률, 승률, 낙폭 같은 숫자를 예측해서 적지 마라.
   - 전체 100줄 이내. 같은 내용을 두 번 쓰지 마라. 위에 없는 절을 추가하지 마라.
     설명은 파일이 아니라 채팅으로 한다.
   - 파일은 research/strategy_candidates.md 외에 만들지 마라.
   - 다 쓰면 파일 경로와 줄 수를 보고하고 멈춰라.
```
