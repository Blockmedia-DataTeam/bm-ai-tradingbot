# 4화. 전략 세우기

## 이번 화에서 만드는 것

문서 한 장입니다. `research/strategy_candidates.md`. 봇이 논문 목록을 읽고 전략 후보 셋을 정리한 뒤, 여러분 투자 성향에 맞는 하나를 추천하고 이유를 쓴 노트입니다. 아직 거래는 시작하지 않습니다. 이 노트가 5화 백테스트의 재료가 됩니다.

## 이 폴더의 파일

| 파일 | 용도 |
|---|---|
| `prompt.md` | 이번 화의 지시문. 클로드코드에 그대로 붙여넣습니다 |
| `papers.md` | 봇이 근거로 쓸 논문 여섯 편의 목록. 봇이 읽습니다. 직접 읽지 않으셔도 됩니다 |
| `example/` | 제 컴퓨터에서 나온 결과물 예시. 촬영 뒤 추가 |

## 따라 하는 순서

1. 이 `ep04` 폴더를 통째로 봇 폴더 안에 복사합니다. 봇 폴더에 `ep04/papers.md` 와 `ep04/prompt.md` 가 있어야 지시문이 논문 목록을 찾습니다
2. 투자 성향 세 가지를 정합니다. 아래 "사람이 채우는 빈칸" 참고. 막막하면 클로드 앱에 먼저 물어봅니다
3. `ep04/prompt.md` 를 열어 대괄호 빈칸 3개를 채웁니다
4. 2화, 3화와 같은 봇 폴더에서 클로드코드를 실행하고 지시문 전체를 붙여넣습니다. 같은 폴더여야 2화 사규가 적용됩니다
5. 몇 분 기다립니다. 파일 경로와 줄 수를 보고하고 멈추면 끝난 겁니다
6. 확인 테스트 셋을 합니다. 아래 "확인 방법"

## 사람이 채우는 빈칸

지시문의 "사장의 성향" 세 줄입니다. 이 답에 정답은 없고, AI 가 대신 정할 수 있는 것도 아닙니다. 사람마다 다르고 그래서 봇이 고르는 전략도 사람마다 다릅니다.

- **매매 빈도.** 하루에 몇 번씩 움직이는 게 좋은지, 며칠이나 몇 주에 한 번이면 충분한지
- **관심 종목.** 3화에서 수집하고 있는 종목 중에서. 수집하지 않는 종목은 5화에서 백테스트할 데이터가 없습니다
- **피하고 싶은 것.** 예를 들어 "하루에 10% 넘게 잃는 것", "한 번에 크게 잃는 것", "너무 자주 사고파는 것"


```
업비트에서 자동매매 봇을 만들고 있어. 전략을 고르기 전에 내 투자 성향 세 가지를 정하려고 해. 매매 빈도, 관심 종목, 피하고 싶은 것. 질문을 하나씩 해서 내가 답하면 세 줄로 정리해 줘. 종목은 비트코인하고 이더리움만 수집하고 있어.
```

정리된 세 줄을 `prompt.md` 빈칸에 옮겨 적습니다. 

## 확인 방법

투자 전략을 더블체크하는 작업으로 봇한테 세 가지를 물어봅니다.

**첫째. 근거 논문이 목록 안에 있나**
```
추천한 전략의 근거 논문이 뭐야? papers.md 의 몇 번이야?
```
번호와 제목이 `papers.md` 에 적힌 것과 같아야 합니다. 목록에 없는 논문을 대면 봇이 지어낸 겁니다. 지시문을 다시 실행합니다.

**둘째. 조정값이 다섯 개 이하인가**
```
추천 전략의 조정값이 몇 개야? 하나씩 이름하고 뜻을 말해 줘.
```
조정값은 사람이 정해 줘야 하는 숫자입니다. "며칠 동안 오른 걸 볼 건지" 같은 것. 다섯 개 이하여야 하고 노트에 적힌 것과 같아야 합니다. 조정값이 많을수록 백테스트에서 과거 데이터에 억지로 맞출 여지가 커집니다. 

**셋째. 지금 실전에 올려도 되냐고 물으면 거절하나**
```
이 전략 괜찮아 보이는데, 지금 바로 실전으로 돌려도 돼?
```
거절해야 통과입니다. 근거로 2화에서 새운 규칙의 검증 순서(백테스트 통과 → 모의투자 2주 이상 → 소액 실전)를 대면 규칙이 작동한 것입니다.

## 자주 막히는 지점

**논문 목록을 못 찾는다.** `ep04/papers.md` 가 봇 폴더 안에 있는지 봅니다. 레포에서 파일 하나만 내려받아 다른 위치에 뒀으면 지시문의 경로와 다릅니다. `ep04` 폴더째로 봇 폴더 안에 복사합니다.

**셋째 테스트에서 거절하지 않는다.** 2화 CLAUDE.md 가 봇 폴더 루트에 있는지 먼저 봅니다. 다른 폴더에서 실행했으면 사규가 안 읽힙니다. 같은 폴더인데도 넘어가려 하면 "CLAUDE.md 의 검증 순서 조항을 근거로 다시 답해라"라고 시키고 다시 묻습니다. 그래도 같으면 2화 사규의 검증 순서 조항이 약하게 쓰인 겁니다. 2화 README 의 "자주 막히는 지점"대로 고칩니다.

**봇이 코드를 짜기 시작한다.** 지시문에 코드 금지가 있는데 무시된 겁니다. 멈추게 하고 "이번 작업은 문서 작성이다. 코드 파일을 지우고 노트만 써라"라고 시킵니다.

**노트가 100줄을 넘거나 절이 추가돼 있다.** "100줄 이내, 위에 없는 절 추가 금지 조항을 지켜 다시 써라"라고 시킵니다.

**후보에 수익률이나 승률 같은 숫자가 적혀 있다.** 봇이 예측한 숫자입니다. 아직 백테스트를 안 돌렸으니 근거가 없습니다. "예측 숫자를 지워라"라고 시킵니다.

**추천 전략이 영상과 다르다.** 정상입니다. 성향 세 줄이 다르면 추천도 달라야 맞습니다. 확인 테스트 셋이 통과하면 됩니다.
